# PostgreSQL Joins

The SQL files are in `solutions`. Run the first file, then the seed file, and then the query you want to check.

```bash
psql -d your_database -f solutions/ex_1.sql
psql -d your_database -f solutions/seed.sql
psql -d your_database -f solutions/ex_2.sql
```

The picture and original data are in `reference-data`.
